# Gerenciador de Tarefas

Este é um simples gerenciador de tarefas desenvolvido em Python. Ele permite que o usuário adicione, liste, edite, remova e marque tarefas como concluídas, armazenando-as em um arquivo JSON para persistência.

## Requisitos

Antes de rodar o código, você precisará de um ambiente virtual Python configurado. Se não tiver o ambiente configurado, siga as instruções abaixo:

### Criação de Ambiente Virtual:

Se você ainda não tem o `venv` instalado, crie um novo ambiente virtual:
